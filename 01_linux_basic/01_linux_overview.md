# 01. 리눅스 개요

## 학습 목표

- 리눅스의 역사와 Unix 계열 운영체제의 흐름을 이해한다.
- 커널, 셸, 배포판의 차이를 설명할 수 있다.
- 리눅스 시스템의 특징과 장점을 명령어로 확인한다.
- 주요 리눅스 배포판의 용도를 구분한다.

## 리눅스의 역사

리눅스는 1991년 Linus Torvalds가 만든 커널에서 시작했다. 커널은 운영체제의 핵심으로, 하드웨어 자원과 프로세스, 메모리, 파일 시스템을 관리한다.

오늘날 우리가 쓰는 "리눅스"는 보통 리눅스 커널에 GNU 도구, 셸, 패키지 관리자, 기본 유틸리티를 묶은 리눅스 배포판을 뜻한다. Ubuntu, Debian, Fedora, Rocky Linux, Arch Linux가 모두 배포판이다.

## 핵심 구성 요소

| 구성 요소 | 설명 | 예 |
| --- | --- | --- |
| 커널 | 하드웨어와 프로그램 사이에서 자원을 관리 | Linux kernel |
| 셸 | 사용자의 명령을 해석해 실행 | Bash, Zsh, Fish |
| 파일 시스템 | 파일과 디렉터리를 계층 구조로 관리 | `/`, `/home`, `/etc` |
| 배포판 | 커널과 도구를 묶어 설치 가능한 형태로 제공 | Ubuntu, Debian |
| 패키지 관리자 | 프로그램 설치와 업데이트 관리 | `apt`, `dnf`, `pacman` |

## 리눅스의 특징과 장점

- 오픈소스 생태계가 크고 서버, 클라우드, 개발 환경에서 널리 쓰인다.
- 명령어와 텍스트 파일 기반 설정이 강력하다.
- 사용자와 권한 모델이 명확하다.
- 작은 도구를 조합해 자동화하기 좋다.
- 같은 명령어 지식이 서버, 컨테이너, 임베디드, WSL 환경으로 이어진다.

## 리눅스 배포판의 종류

| 계열 | 대표 배포판 | 특징 |
| --- | --- | --- |
| Debian 계열 | Debian, Ubuntu | 안정적이고 자료가 많으며 초보자에게 적합 |
| Red Hat 계열 | RHEL, Rocky Linux, AlmaLinux, Fedora | 기업 서버 환경에서 많이 사용 |
| Arch 계열 | Arch Linux, Manjaro | 최신 패키지와 높은 사용자 자유도 |
| SUSE 계열 | openSUSE, SUSE Linux Enterprise | 유럽 기업 환경과 관리 도구 강점 |

수업에서는 WSL에서 설치가 쉽고 자료가 많은 Ubuntu를 기준으로 한다.

## 시스템 정보 확인

Ubuntu 터미널에서 실행한다.

```bash
# 커널 이름, 버전, 시스템 아키텍처를 확인한다
uname -a

# Ubuntu 배포판 이름과 버전을 확인한다
cat /etc/os-release

# 시스템 호스트 이름을 출력한다
hostname

# 현재 로그인한 사용자 이름을 출력한다
whoami

# 현재 사용자의 UID, GID, 그룹 정보를 출력한다
id
```

각 명령의 의미는 다음과 같다.

| 명령어 | 확인하는 내용 |
| --- | --- |
| `uname -a` | 커널 이름, 버전, 아키텍처 |
| `cat /etc/os-release` | 배포판 이름과 버전 |
| `hostname` | 시스템 이름 |
| `whoami` | 현재 사용자 이름 |
| `id` | 사용자 ID, 그룹 ID |

## 기본 상태 확인 명령

```bash
# 현재 날짜와 시간을 출력한다
date

# 시스템 실행 시간과 부하 평균을 확인한다
uptime

# 메모리 사용량을 사람이 읽기 쉬운 단위로 확인한다
free -h

# 파일 시스템별 디스크 사용량을 확인한다
df -h

# 현재 작업 디렉터리를 출력한다
pwd

# 현재 디렉터리의 파일 목록을 출력한다
ls
```

`free -h`는 메모리 사용량을 사람이 읽기 쉬운 단위로 보여준다. `df -h`는 파일 시스템의 디스크 사용량을 보여준다.

## WSL에서 확인할 점

WSL도 리눅스 사용자 공간을 제공하지만 일반 서버와 완전히 같지는 않다. 예를 들어 커널은 Microsoft가 WSL용으로 제공하고, Windows 파일 시스템은 `/mnt/c` 아래에 연결된다.

```bash
# WSL에서 사용하는 리눅스 커널 버전을 확인한다
uname -r

# WSL에 연결된 마운트 지점을 확인한다
ls /mnt

# 현재 마운트된 파일 시스템 일부를 확인한다
mount | head
```

## 확인 과제

1. 현재 Ubuntu 배포판의 이름과 버전을 찾는다.
2. 현재 사용자 이름, 사용자 ID, 기본 그룹을 확인한다.
3. `/`, `/home`, `/mnt` 디렉터리의 역할을 한 줄씩 정리한다.
4. Ubuntu와 Rocky Linux의 차이를 "배포판" 관점에서 설명한다.
