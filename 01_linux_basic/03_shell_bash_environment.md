# 03. 셸과 Bash 환경

## 학습 목표

- 셸의 역할과 종류를 이해한다.
- Bash에서 명령어가 실행되는 과정을 설명한다.
- 셸 변수와 환경 변수를 구분한다.
- 프롬프트와 `.bashrc`를 간단히 설정한다.

## 셸의 역할

셸은 사용자가 입력한 명령을 해석하고 실행하는 프로그램이다. 리눅스에서 명령어를 입력하면 셸이 명령어를 찾고, 옵션과 인자를 해석한 뒤 프로그램을 실행한다.

대표적인 셸은 다음과 같다.

| 셸 | 특징 |
| --- | --- |
| `sh` | 오래된 표준 셸 계열 |
| `bash` | Ubuntu의 기본 셸, 수업 기준 |
| `zsh` | 확장 기능과 프롬프트 꾸미기에 강함 |
| `fish` | 사용 편의성이 높은 셸 |

현재 셸을 확인한다.

```bash
# 현재 사용자의 기본 로그인 셸 경로를 출력한다
echo "$SHELL"

# 현재 실행 중인 셸 프로세스 이름을 출력한다
ps -p $$ -o comm=

# 시스템에서 사용할 수 있는 셸 목록을 확인한다
cat /etc/shells
```

## 명령어 찾기

셸은 명령어를 입력받으면 `PATH` 환경 변수에 등록된 디렉터리에서 실행 파일을 찾는다.

```bash
# 명령어를 찾을 디렉터리 목록을 출력한다
echo "$PATH"

# ls가 별칭, 내장 명령, 외부 명령 중 무엇인지 확인한다
type ls

# bash 실행 파일의 위치를 확인한다
command -v bash

# bash 실행 파일의 위치를 which 명령으로도 확인한다
which bash
```

`type`은 셸 내장 명령, 별칭, 외부 명령을 함께 알려주므로 명령어의 정체를 확인할 때 유용하다.

## 셸 변수와 환경 변수

셸 변수는 현재 셸 안에서만 쓴다.

```bash
# course라는 셸 변수를 만든다
course="linux"

# 셸 변수 값을 출력한다
echo "$course"
```

환경 변수는 현재 셸에서 실행되는 하위 프로세스에도 전달된다.

```bash
# 하위 프로세스에도 전달되는 환경 변수를 만든다
export COURSE_NAME="linux-basic"

# 환경 변수 목록에서 COURSE_NAME을 검색한다
env | grep COURSE_NAME

# 새 Bash 프로세스에서도 환경 변수가 보이는지 확인한다
bash -c 'echo "$COURSE_NAME"'
```

셸 변수는 새 Bash 프로세스에 전달되지 않는다.

```bash
# 현재 셸에서만 사용할 셸 변수를 만든다
temporary_value="hello"

# 새 Bash 프로세스에서는 셸 변수가 전달되지 않는지 확인한다
bash -c 'echo "$temporary_value"'
```

## 자주 쓰는 환경 변수

| 변수 | 의미 |
| --- | --- |
| `HOME` | 현재 사용자의 홈 디렉터리 |
| `USER` | 현재 사용자 이름 |
| `SHELL` | 기본 로그인 셸 |
| `PATH` | 명령어 검색 경로 |
| `PWD` | 현재 작업 디렉터리 |
| `LANG` | 언어와 문자 인코딩 설정 |

확인해 본다.

```bash
# 현재 사용자의 홈 디렉터리를 출력한다
echo "$HOME"

# 현재 사용자 이름을 출력한다
echo "$USER"

# 현재 작업 디렉터리를 출력한다
echo "$PWD"

# 현재 언어와 문자 인코딩 설정을 출력한다
echo "$LANG"
```

## 프롬프트 설정

Bash 프롬프트는 `PS1` 변수로 정한다. 임시로 바꿔 본다.

```bash
# 프롬프트를 수업용 형식으로 임시 변경한다
PS1='linux-class:\w$ '
```

프롬프트를 원래대로 되돌리려면 새 터미널을 열거나 다음처럼 기본 형태를 넣는다.

```bash
# 프롬프트를 기본 사용자@호스트:경로 형식으로 되돌린다
PS1='\u@\h:\w\$ '
```

자주 쓰는 프롬프트 기호는 다음과 같다.

| 기호 | 의미 |
| --- | --- |
| `\u` | 사용자 이름 |
| `\h` | 호스트 이름 |
| `\w` | 현재 작업 디렉터리 |
| `\$` | 일반 사용자는 `$`, root는 `#` |

## .bashrc 이해

`~/.bashrc`는 새 Bash 셸이 열릴 때 실행되는 설정 파일이다. 별칭, 환경 변수, 프롬프트 설정을 넣을 수 있다.

먼저 백업한다.

```bash
# 현재 Bash 설정 파일을 백업한다
cp ~/.bashrc ~/.bashrc.bak
```

수업용 별칭을 추가한다.

```bash
# ll 명령을 ls -alF 별칭으로 등록한다
echo "alias ll='ls -alF'" >> ~/.bashrc

# 수업명을 환경 변수로 등록한다
echo "export COURSE_NAME='linux-basic'" >> ~/.bashrc

# 수정한 Bash 설정을 현재 셸에 즉시 적용한다
source ~/.bashrc
```

동작을 확인한다.

```bash
# 새로 등록한 ll 별칭을 실행한다
ll

# 등록한 환경 변수 값을 확인한다
echo "$COURSE_NAME"
```

백업으로 되돌리고 싶다면 다음을 실행한다.

```bash
# 백업해 둔 .bashrc로 되돌린다
cp ~/.bashrc.bak ~/.bashrc

# 되돌린 설정을 현재 셸에 즉시 적용한다
source ~/.bashrc
```

## 히스토리와 자동 완성

Bash는 입력한 명령어를 기록한다.

```bash
# 최근에 실행한 명령어 기록의 마지막 부분을 확인한다
history | tail
```

방향키 위/아래로 이전 명령을 탐색할 수 있고, `Ctrl + r`로 명령어 이력을 검색할 수 있다. 파일명이나 명령어 일부를 입력한 뒤 `Tab`을 누르면 자동 완성을 시도한다.

## 확인 과제

1. 현재 셸과 Bash 실행 파일 위치를 확인한다.
2. `PATH`에 들어 있는 디렉터리를 `:` 기준으로 나눠 살펴본다.
3. 셸 변수와 환경 변수의 차이를 예제로 설명한다.
4. `ll` 별칭을 등록하고 새 터미널에서도 동작하는지 확인한다.

```bash
# ll 별칭을 .bashrc에 추가한다
echo "alias ll='ls -alF'" >> ~/.bashrc

# .bashrc 변경사항을 현재 셸에 적용한다
source ~/.bashrc

# ll 별칭이 동작하는지 확인한다
ll
```

새 터미널을 열고 `ll`이 동작하면 `.bashrc` 설정이 적용된 것이다.
