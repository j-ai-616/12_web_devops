# 04. vi 편집기

## 학습 목표

- 리눅스에서 편집기가 필요한 상황을 이해한다.
- `vi`의 명령 모드, 입력 모드, 라인 모드를 구분한다.
- 파일을 열고 수정한 뒤 저장하고 종료한다.
- 기본 이동, 삭제, 복사, 붙여넣기, 검색 명령을 사용한다.

## vi란?

`vi`는 대부분의 리눅스 환경에 기본으로 들어 있는 텍스트 편집기이다. 서버에서는 GUI 편집기를 사용할 수 없는 경우가 많기 때문에 터미널 편집기 사용법을 알아두면 좋다.

Ubuntu에는 `vi` 또는 `vim.tiny`가 기본 제공되는 경우가 많다. 더 편한 Vim을 설치하려면 다음을 사용할 수 있다.

```bash
# 패키지 목록을 최신 상태로 갱신한다
sudo apt update

# Vim 편집기를 설치한다
sudo apt install vim
```

## 실습 파일 만들기

Ubuntu 터미널에서 실행한다.

```bash
# vi 실습용 디렉터리를 만든다
mkdir -p ~/linux-class/vi-lab

# vi 실습용 디렉터리로 이동한다
cd ~/linux-class/vi-lab

# memo.txt 파일에 초기 내용을 작성한다
printf "Linux\nShell\nEditor\n" > memo.txt

# vi로 memo.txt 파일을 연다
vi memo.txt
```

## vi의 세 가지 모드

| 모드 | 역할 | 진입 방법 |
| --- | --- | --- |
| 명령 모드 | 이동, 삭제, 복사, 붙여넣기 | `Esc` |
| 입력 모드 | 실제 텍스트 입력 | `i`, `a`, `o` |
| 라인 모드 | 저장, 종료, 검색, 설정 | 명령 모드에서 `:` |

vi를 열면 기본적으로 명령 모드이다. 글자가 입력되지 않는다면 명령 모드일 가능성이 크다.

## 입력과 저장

1. `i`를 눌러 입력 모드로 들어간다.
2. 원하는 내용을 입력한다.
3. `Esc`를 눌러 명령 모드로 돌아온다.
4. `:w`를 입력하고 Enter를 눌러 저장한다.
5. `:q`를 입력하고 Enter를 눌러 종료한다.

저장하고 바로 종료하려면 다음을 사용한다.

```text
:wq
```

저장하지 않고 강제로 종료하려면 다음을 사용한다.

```text
:q!
```

## 입력 모드 진입 키

| 키 | 설명 |
| --- | --- |
| `i` | 현재 커서 앞에서 입력 |
| `a` | 현재 커서 뒤에서 입력 |
| `o` | 현재 줄 아래 새 줄을 만들고 입력 |
| `O` | 현재 줄 위 새 줄을 만들고 입력 |

## 명령 모드 이동

| 키 | 설명 |
| --- | --- |
| `h` | 왼쪽 |
| `j` | 아래 |
| `k` | 위 |
| `l` | 오른쪽 |
| `0` | 줄의 처음 |
| `$` | 줄의 끝 |
| `gg` | 파일의 처음 |
| `G` | 파일의 끝 |

방향키도 동작하는 경우가 많지만, 기본 키를 익혀두면 어떤 환경에서도 사용할 수 있다.

## 삭제, 복사, 붙여넣기

| 키 | 설명 |
| --- | --- |
| `x` | 커서 위치의 글자 삭제 |
| `dd` | 현재 줄 삭제 |
| `yy` | 현재 줄 복사 |
| `p` | 커서 아래 또는 뒤에 붙여넣기 |
| `u` | 실행 취소 |

숫자를 붙이면 반복된다.

```text
3dd
5yy
```

## 검색과 라인 모드

명령 모드에서 `/검색어`를 입력하면 아래 방향으로 검색한다.

```text
/Shell
```

다음 검색 결과로 이동하려면 `n`, 이전 결과로 이동하려면 `N`을 누른다.

라인 번호를 켠다.

```text
:set number
```

라인 번호를 끈다.

```text
:set nonumber
```

특정 줄로 이동한다.

```text
:3
```

## 확인 과제

1. `memo.txt`에 자신의 이름과 오늘 배운 명령어 3개를 추가한다.
2. 한 줄을 복사해 아래에 붙여넣는다.
3. 한 줄을 삭제한 뒤 `u`로 되돌린다.
4. `Shell`이라는 단어를 검색한다.
5. 저장 후 종료하고 `cat memo.txt`로 결과를 확인한다.
